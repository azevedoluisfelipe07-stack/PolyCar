# PolyCar
PolyCar é um jogo de direção 3D com visual low-poly, terrenos variados e estradas para explorar. Dirija por paisagens com lagos, pontes, curvas e relevos, aproveite diferentes cenários e experimente uma condução livre com piloto automático. Uma experiência leve e imersiva, feita para transformar cada viagem em uma nova aventura.
