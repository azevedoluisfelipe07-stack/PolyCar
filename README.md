# PolyCar

**PolyCar** é um jogo de direção 3D com estética low-poly, desenvolvido para proporcionar uma experiência de condução livre, exploração de cenários e diversão em um ambiente virtual.

## Sobre o projeto

O PolyCar combina gráficos geométricos estilizados com ambientes variados, estradas e elementos naturais para criar um mundo interessante de explorar. A proposta é oferecer uma experiência de direção simples, leve e imersiva, diretamente no navegador.

## Recursos

- **Mundo 3D:** explore um ambiente tridimensional com visual low-poly.
- **Terrenos variados:** dirija por diferentes tipos de paisagens e superfícies.
- **Estradas detalhadas:** percorra caminhos com curvas, elevações e relevos.
- **Lagos e pontes:** descubra elementos que enriquecem o cenário e tornam os trajetos mais interessantes.
- **Modelo de carro:** veículo com aparência estilizada, integrado ao ambiente do jogo.
- **Piloto automático:** recurso para auxiliar na condução.
- **Variações de iluminação:** aproveite diferentes atmosferas e condições de iluminação.
- **Execução no navegador:** jogue sem precisar instalar um jogo tradicional.

## Objetivo

O PolyCar prioriza a liberdade de dirigir e explorar. Você pode percorrer as estradas, observar as paisagens e experimentar diferentes trajetos, sem que a experiência dependa apenas de chegar a um destino específico.

## Tecnologias

O projeto utiliza tecnologias web para renderizar e executar o ambiente 3D no navegador.

- **HTML:** estrutura da aplicação.
- **CSS:** interface e elementos visuais.
- **JavaScript:** lógica do jogo e interações.
- **Three.js:** renderização gráfica em 3D utilizando WebGL.

## Como executar

1. Baixe ou clone os arquivos do projeto.
2. Mantenha os arquivos necessários na estrutura original.
3. Abra o arquivo HTML principal em um navegador compatível.

Se o projeto utilizar recursos que exigem um servidor local, execute-o por meio de uma ferramenta como o Live Server.

## Visão do projeto

A ideia do PolyCar é unir simplicidade, exploração e direção em uma experiência acessível. O estilo low-poly contribui para uma identidade visual própria, enquanto os terrenos, as estradas e os elementos do cenário tornam cada percurso mais interessante.

## Status

Projeto em desenvolvimento. Recursos, cenários, controles e otimizações podem mudar conforme novas versões forem criadas.
